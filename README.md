# Mystic Forest Content

This public repository stores the catalog and sprites used by the Mystic Forest tab.
Read [CLAUDE.md](CLAUDE.md) for the content rules.

Run `python3 scripts/validate.py` to validate the catalog and sprites.
Add new items by asking an agent that has read `CLAUDE.md`.

## Staged trees

Cherry Blossom Tree (`cherry_blossom`) has approved base artwork and is disabled pending release decisions. Its required `tokenPrice` of 3 is the standard tree placeholder. Confirm the purchase and placement prices, unlock and availability before enabling it.

Its Winter appearance was approved in the complete Winter review. Both base and Winter artwork are staged in this draft. The Winter pack remains disabled; this art approval does not select an item unlock, purchase window, final price, or pack activation date. Autumn artwork still requires separate approval.
