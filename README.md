# Mystic Forest Content

This public repository stores the catalog and sprites used by the Mystic Forest tab.
Read [CLAUDE.md](CLAUDE.md) for the content rules.

Gold Vein (`gold_vein`) is a staged 2×2 landmark. Its required `tokenPrice` of 4 is the repository’s placement-price placeholder. Confirm prices, unlock and availability before enabling it.

Run `python3 scripts/validate.py` to validate the catalog and sprites.
Add new items by asking an agent that has read `CLAUDE.md`.
